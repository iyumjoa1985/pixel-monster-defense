# 픽셀 몬스터 디펜스

브라우저에서 바로 실행되는 타워 디펜스 게임입니다. 설치할 것 없이 `index.html`을 열면 됩니다.

- 몬스터들이 동굴에서 나와 길을 따라 마을로 걸어옵니다. 마을에 도착하면 생명이 줄고, 생명이 0이 되면 패배입니다.
- 풀밭을 클릭해 타워(오리지널 픽셀 몬스터)를 심고, 골드를 모아 진화시키세요.
- 속성 상성: 🔥불 → 🌿풀 → 💧물 → 🔥불 순서로 1.5배 강합니다.
- 10웨이브마다 보스가 나오고, 20웨이브를 막아내면 승리입니다. 승리 후엔 끝없는 모드로 계속할 수 있습니다.

## 친구와 함께 (온라인 협동)

- 위쪽 "👥 친구와 함께" 버튼 → "방 만들기"를 누르면 4글자 방 코드와 링크가 나옵니다.
- 친구는 같은 버튼에서 코드를 넣거나, 받은 링크(`?room=코드`)를 열면 바로 들어옵니다.
- 골드·생명·타워를 둘이 같이 씁니다. 둘 다 타워를 심고, 진화시키고, 팔고, 웨이브를 시작할 수 있어요.
- 방장 컴퓨터가 게임을 계산하고 친구 화면은 그 결과를 받아 보여줍니다(둘의 화면이 어긋나지 않게). 방장이 다른 탭을 보면 게임이 잠시 멈춥니다.
- 연결은 무료 공개 서버(PeerJS)가 소개만 해 주고 두 브라우저가 직접 이어집니다. 일부 통신 환경에서는 연결이 안 될 수 있습니다.

## 조작

| 할 일 | 방법 |
|---|---|
| 타워 고르기 | 카드 클릭 또는 숫자키 1·2·3 |
| 타워 심기 | 풀밭 클릭 |
| 타워 정보·진화 | 심은 타워 클릭 → 진화 버튼 또는 E키 |
| 타워 팔기 | 타워 오른쪽 클릭, 또는 팔기 버튼 / Delete키 |
| 일시정지 | 버튼 또는 스페이스바 |
| 소리 끄기 | 🔊 버튼 |

## 폴더 구성

- `index.html`, `style.css` — 화면
- `js/sprites.js` — 픽셀 몬스터 도감 (12×12, 보스는 16×16 글자 격자)
- `js/game.js` — 게임 규칙 (경로, 타워, 적, 골드, 웨이브, 보스)
- `js/sound.js` — 효과음·배경음 (소리 파일 없이 Web Audio로 직접 생성)
- `test/play-test.js` — 자동 플레이 테스트

## 자동 테스트

Node.js와 Chrome이 설치되어 있으면 다음 명령으로 게임을 자동으로 플레이하며 검사합니다.

```
npm install
npm test
```

## 만든 사람

모든 캐릭터는 직접 그린 오리지널 픽셀 몬스터입니다.
